# 1. Overview

Cloud Firestore serves as the central database for DigiIndia.

Every module stores only structured metadata.

Large files are stored in Cloudinary.

Firestore stores

• References
• Metadata
• Relationships
• Permissions
• Analytics
• AI Results

# 35. Database Philosophy

Firestore should remain the single source of truth for structured application data.

Heavy assets remain in Cloudinary.

AI-generated content remains modular.

Relationships are normalized wherever practical to improve scalability, querying, and long-term maintenance across the DigiIndia Student Innovation Platform.
