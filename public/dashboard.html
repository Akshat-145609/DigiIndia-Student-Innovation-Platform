Developer API Documentation & Integration Guide

Use your X-DigiIndia-Key to integrate DigiIndia AI responses and project queries into external domains (e.g. Codagenda).
1. Authentication Header

Pass your generated API secret key in the request header:

X-DigiIndia-Key: digi_live_YOUR_GENERATED_API_KEY
2. JavaScript Fetch Example (AI Response in Codagenda)
async function fetchDigiIndiaAI(promptText) {
  const response = await fetch("http://localhost:8000/api/v1/ai/assistant", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-DigiIndia-Key": "YOUR_GENERATED_API_KEY"
    },
    body: JSON.stringify({ prompt: promptText })
  });
  const data = await response.json();
  console.log("AI Knowledge Response:", data.reply);
  return data.reply;
}
3. Fetch Public Verified Student Projects
fetch("http://localhost:8000/api/v1/search/projects?q=python&verified_only=true", {
  headers: { "X-DigiIndia-Key": "YOUR_GENERATED_API_KEY" }
})
.then(res => res.json())
.then(projects => console.log(projects));
